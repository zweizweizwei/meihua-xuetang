## ⚙️ 架构设计

### 记忆曲线复习机制

每关开头增加 **「温故知新」** 环节（2-3 题），从已通关内容中按以下间隔抽取：

| 间隔 | 概率权重 | 说明 |
|------|---------|------|
| 刚通关 | 50% | 当天或次日重出 |
| 3 天前 | 30% | 三天前通关的内容 |
| 7 天前 | 15% | 一周前 |
| 14 天前 | 5% | 两周前 |

实现方式：localStorage 记录每关 `lastCompleted` 时间戳，进入关卡时自动计算并抽题。

### 知识验证来源

所有教学内容必须标注或基于以下经典，禁止凭 AI 记忆瞎编：

| 经典 | 涵盖内容 |
|------|---------|
| 《周易·说卦传》 | 八卦取象（人物/动物/身体/方位） |
| 《周易·系辞传》 | 八卦生成原理、爻变 |
| 《尚书·洪范》 | 五行生克本源 |

## 🧱 第一单元：基础三件套（第1-20关）

### 已有关卡

#### 第1关：八卦入门 ✅
- **教学内容**：八卦符号(☰☱☲☳☴☵☶☷)、名称、五行属性、取象口诀
- **来源**：《周易·说卦传》
- **题型**：符号→名称、名称→符号、口诀→卦名、五行配对（20题）
- **调整建议**：可微调题目分布，确保每个卦的覆盖均衡

#### 第2关：五行生克 ✅  
- **教学内容**：五行相生链(木→火→土→金→水→木)、相克链(木→土→水→火→金→木)
- **来源**：《尚书·洪范》
- **题型**：生克判断、逆推、两两关系（20题）
- **调整建议**：可增加「多步生克链」题型（如「木生什么生什么？」链式推理）

#### 第4关：八卦动物类象

#### 第5关：八卦身体类象

- **教学**：汇总表——卦/人物/动物/身体/方位/季节/自然

### 第9-10关：爻与卦的结构

#### 第9关：爻的认识
- **教学**：阳爻(⚊)、阴爻(⚋)、六爻位（从下往上：初、二、三、四、五、上）、当位（奇数位阳爻、偶数位阴爻为当位）
- **来源**：《周易·系辞传》
- **题型**：识别阴阳、判断爻位名称、当位判断（20题）
- **记忆曲线**：2 题来自第1-8关

#### 第10关：上卦下卦
- **教学**：重卦 = 上卦(外卦) + 下卦(内卦)，六爻分上下
- **来源**：《周易》
- **题型**：拆分上下卦、给定上下卦组合成重卦、识别重卦的上下卦（20题）
- **记忆曲线**：2 题来自第1-9关

### 第11-13关：五行万物类象

#### 第11关：五行方位+季节+颜色

#### 第12关：五行五脏+五味+五志

#### 第13关：五行综合大挑战

- **记忆曲线**：仅回顾

### 第14-17关：体用判断

#### 第14关：体用概念入门
- **教学**：体=静卦代表自己，用=动爻所在卦代表对方，如何找动爻
- **来源**：邵雍《梅花易数》卷一「体用总诀」
- **题型**：给定上卦下卦+动爻位置，判断体卦和用卦（20题）
- **记忆曲线**：2 题来自第1-13关

#### 第15关：体用生克关系
- **教学**：体用之间的五行生克——体生用、用生体、体克用、用克体、体用比和
- **来源**：《梅花易数》「体用生克篇」
- **题型**：给体卦用卦→判断生克关系（20题）
- **记忆曲线**：3 题来自八卦+五行关

#### 第16关：体用吉凶速断
- **教学**：用生体=大吉、比和=吉、体克用=小吉、体生用=小凶、用克体=凶
- **来源**：《梅花易数》
- **题型**：速断吉凶等级+解释原因（20题）
- **记忆曲线**：3 题来自前序关

#### 第17关：体用实战综合
- **教学**：完整体用判断流程
- **题型**：给重卦+动爻→找体用→判断生克→断吉凶（20题）
- **记忆曲线**：大量复习前序内容

## 🔧 技术实现细节

### 记忆曲线模块
```javascript
function getReviewQuestions(completedLevels, currentLevel) {
  // 从 completedLevels 中按间隔权重抽取 2-3 道旧题
  // 优先：最近通关的 + 间隔命中的
  const now = Date.now();
  const candidates = completedLevels.filter(l => {
    const days = (now - l.completedAt) / 86400000;
    return Math.random() < getWeight(days);
  });
  return shuffle(candidates).slice(0, 3);
}
```
